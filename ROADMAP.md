# Roadmap

## Phase 1

- stabilize `init`, `validate`, `inspect`, `build`, and `install`
- add target-specific validation rules
- add richer context footprint reporting

## Phase 2

- add lockfiles for reproducible pack builds
- add local registry metadata and pack catalogs
- add remote pack fetch and integrity checks

## Phase 3

- add signed bundles
- add policy rules for internal team packs
- add pack discovery metadata for future registries
