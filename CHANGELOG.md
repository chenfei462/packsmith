# Changelog

## 0.1.0

First public stable preview release for `@chenfei462/packsmith`.

- Publish path: GitHub Release `v0.1.0` triggers npm trusted publishing with provenance.
- Proof path: `npm run verification:sync` regenerates README proof signals and `docs/verification.*`.
- Distribution docs: npm global install, tarball install, Claude Code scoped install, and Codex `--dest` install are documented as launch verification paths.
- Launch package: release playbook, launch kit, post-publish proof refresh workflow, and reusable GitHub release-note grouping.
