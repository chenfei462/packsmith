# Positioning

## What Packsmith is

A zero-dependency CLI that turns one source pack into portable, target-specific agent skill bundles.

## What Packsmith is not

- not another giant skill library
- not an agent framework
- not a hosted marketplace
- not a cloud product

## Core wedge

Most repos in the category ship content. Packsmith ships portability.

## The simple pitch

If you maintain agent skills for more than one runtime, Packsmith removes the duplication layer.
