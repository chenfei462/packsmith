# Incident Postmortem

Use the Incident Postmortem pack to help with this request.

## Context To Collect

- User goal and current constraint.
- Relevant files, commands, logs, diffs, or docs.
- What has already been tried or decided.

## Task

Handle the request when the user needs a clear incident review from notes, logs, or chat summaries.

Follow this sequence:

1. Extract timeline facts without assigning blame.
2. Separate customer impact, detection, mitigation, and root causes.
3. Turn contributing factors into concrete follow-up work.
4. Call out unknowns that still need investigation.

## Output Format

Return:

- timeline
- impact
- root cause
- follow-up actions
