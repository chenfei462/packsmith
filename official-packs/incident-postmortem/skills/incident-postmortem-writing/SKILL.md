# Incident Postmortem

Use this skill when the user needs a clear incident review from notes, logs, or chat summaries.

## Workflow

1. Extract timeline facts without assigning blame.
2. Separate customer impact, detection, mitigation, and root causes.
3. Turn contributing factors into concrete follow-up work.
4. Call out unknowns that still need investigation.

## Return

- timeline
- impact
- root cause
- follow-up actions
