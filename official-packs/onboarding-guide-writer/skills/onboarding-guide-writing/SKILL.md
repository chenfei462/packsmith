# Onboarding Guide Writer

Use this skill when a repository needs a practical first-hour guide for new contributors.

## Workflow

1. Identify install, test, build, and run commands from the repo itself.
2. Explain the smallest useful workflow before advanced internals.
3. Map important directories and ownership boundaries.
4. List common setup problems and how to verify the environment.

## Return

- quick start
- repo map
- common tasks
- troubleshooting

## Runtime Notes

- Claude Code: installed as a skill directory and triggered by this SKILL.md.
- Codex: installed with an AGENTS.md bridge that lists this skill.
- OpenCode: installed with PACKSMITH.md bridge notes beside copied assets.
- Cursor: installed with a generated .mdc rule that points to copied assets.
