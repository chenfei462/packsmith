# Onboarding Guide Writer

Use the Onboarding Guide Writer pack to help with this request.

## Context To Collect

- User goal and current constraint.
- Relevant files, commands, logs, diffs, or docs.
- What has already been tried or decided.

## Task

Handle the request when a repository needs a practical first-hour guide for new contributors.

Follow this sequence:

1. Identify install, test, build, and run commands from the repo itself.
2. Explain the smallest useful workflow before advanced internals.
3. Map important directories and ownership boundaries.
4. List common setup problems and how to verify the environment.

## Output Format

Return:

- quick start
- repo map
- common tasks
- troubleshooting
