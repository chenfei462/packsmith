# Codebase Modernizer

Use the Codebase Modernizer pack to help with this request.

## Context To Collect

- User goal and current constraint.
- Relevant files, commands, logs, diffs, or docs.
- What has already been tried or decided.

## Task

Handle the request when a repository needs framework, language, module, or tooling modernization.

Follow this sequence:

1. Identify the business or developer pain driving modernization.
2. Find a migration path that preserves shipping behavior.
3. Separate tooling updates, source changes, and compatibility adapters.
4. Choose verification gates before expanding scope.

## Output Format

Return:

- modernization goal
- phased plan
- compatibility risks
- verification gates
