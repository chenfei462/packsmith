# Architecture Decision Recorder

Use the Architecture Decision Recorder pack to help with this request.

## Context To Collect

- User goal and current constraint.
- Relevant files, commands, logs, diffs, or docs.
- What has already been tried or decided.

## Task

Handle the request when a technical decision needs to be recorded for future maintainers.

Follow this sequence:

1. Write the decision in one direct sentence.
2. Capture context and constraints that made the decision necessary.
3. Compare rejected alternatives fairly.
4. List consequences, follow-ups, and review date if useful.

## Output Format

Return:

- decision
- context
- alternatives
- consequences
