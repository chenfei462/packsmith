# Competitor Breakdown

Use this skill when users need to understand alternatives, differentiation, pricing, capabilities, or launch positioning.

## Trigger Conditions

- The user names this workflow directly.
- The task matches the pack description: Compares a project against competitors and identifies practical differentiation.
- The work would benefit from a repeatable agent process with clear evidence and output.

## Workflow

1. Identify direct, adjacent, and substitute competitors for the user's job.
2. Compare user promise, first-session experience, distribution, maturity, and missing pieces.
3. Separate feature parity from meaningful differentiation.
4. Find wedges where the project can win without pretending to be bigger than it is.
5. Turn comparison into messaging and product priorities.

## Output Format

Return:

- competitor set
- comparison matrix
- differentiators
- risks
- recommended positioning

```text
packsmith install competitor-breakdown
```
